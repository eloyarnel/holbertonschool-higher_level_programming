# SQL - More Queries

## Description
This project continues the introduction to SQL by focusing on more advanced queries and database management concepts. It covers user privileges, constraints, subqueries, joins, and working with multiple related tables in MySQL.

The objective is to strengthen the understanding of relational databases and learn how to retrieve, filter, and organize data across linked tables.

## Learning Objectives
At the end of this project, you should be able to explain:

- How to create a new MySQL user
- How to manage privileges for a user
- What a PRIMARY KEY is
- What a FOREIGN KEY is
- How to use NOT NULL and UNIQUE constraints
- How to retrieve data from multiple tables
- The difference between INNER JOIN and LEFT JOIN
- How to use subqueries
- How to combine filtering, grouping, and sorting in SQL

## Requirements
- Ubuntu 20.04 LTS
- MySQL 8.0
- All SQL queries must be written in `.sql` files
- All files should end with a new line
- The database name will be passed as an argument of the `mysql` command
- You are not allowed to use more than the required number of `SELECT` statements for each task

## Concepts Covered
- User creation and privileges
- Table constraints
- Relationships between tables
- Joins
- Subqueries
- Aggregation functions
- Ordering and filtering results
