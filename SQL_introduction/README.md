# SQL - Introduction

## Description

This project introduces the fundamentals of SQL (Structured Query Language) and relational databases using MySQL. The tasks focus on creating databases and tables, inserting and retrieving data, and organizing query results using basic SQL statements.

The goal is to understand how databases store structured information and how SQL is used to interact with that data.

## Learning Objectives

By the end of this project, you should be able to explain:

* What a database is
* What a relational database is
* What SQL stands for
* How to create and delete a database
* How to create and modify tables
* How to insert, update, and delete data
* How to retrieve data using SELECT
* How to filter results using WHERE
* How to sort results using ORDER BY
* Basic MySQL commands

## Example SQL Query

```
SELECT score, name
FROM second_table
ORDER BY score DESC;
```

This query selects the columns `score` and `name` from the table `second_table` and orders the results from highest score to lowest.
