# Python - Input/Output

##  Description

This project covers file handling and JSON manipulation in Python, including reading/writing files, serialization, and command-line arguments.

---

##  Learning Objectives

* Open, read, write, and close files
* Use `with` for safe file handling
* Read files line by line
* Understand JSON, serialization, and deserialization
* Convert Python ↔ JSON
* Use command-line arguments (`sys.argv`)

---

##  Requirements

* Python 3.8.5 (Ubuntu 20.04)
* First line: `#!/usr/bin/python3`
* Files must be executable and end with a new line
* Follow **pycodestyle (2.7.*)**
* Allowed editors: `vi`, `vim`, `emacs`

---

##  Tests

* Located in `tests/` folder
* Use `.txt` files
* Run:

  ```bash
  python3 -m doctest ./tests/*
  ```
* All modules, classes, and functions must have proper documentation

---

##  Key Concepts

* File handling (`open`, `read`, `write`)
* `with` statement
* JSON (`json.dumps`, `json.loads`)
* Serialization & deserialization
* Command-line arguments

---

##  Usage

```bash
./script.py file.txt
```
