# More Data Structures: Set, Dictionary (Python)

## Description
This project expands on Python data structures by focusing on **sets** and **dictionaries**.
You will practice how to store unique values with sets, manage key-value pairs with dictionaries, and apply common operations like membership checks, iteration, updates, and transformations.

The goal is to write clean functions that solve problems using the right structure: **set** for uniqueness and fast membership, and **dict** for mapping and quick lookups by key.

---

## Learning Objectives
By the end of this project, you should be able to explain and use:

- What a **set** is and when to use it
- Set operations: **union**, **intersection**, **difference**
- How to iterate through a set and why order is not guaranteed
- What a **dictionary** is (key-value pairs)
- How to add, update, and delete dictionary entries
- How to iterate over dictionaries using:
  - keys
  - values
  - items (key, value)
- When to use `get()` to avoid KeyError
- How to use `len()`, `in`, and loops effectively with sets/dicts
- Basic time-complexity intuition: membership checks in sets/dicts are generally fast
