Project Exceptions
Description:

This project is about handling errors and exceptions in Python.
It focuses on using try, except, and finally to prevent programs from crashing and to handle invalid operations properly.
#----------------------------------------------------------------
Learning Objectives:

At the end of this project, you should be able to:

Understand what exceptions are in Python

Use try, except, and finally

Handle common runtime errors

Raise built-in exceptions manually

Write safer and more reliable Python code
#----------------------------------------------------------------
Requirements:

Python 3.x

No external modules allowed

Mandatory use of try / except / finally where required

Follow Python coding style guidelines
