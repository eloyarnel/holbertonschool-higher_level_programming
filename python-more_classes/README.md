# Python - More Classes and Objects

## Description
This project focuses on Object-Oriented Programming (OOP) in Python using a `Rectangle` class.
It covers encapsulation with private attributes, properties (getters/setters), instance and class attributes, special methods (`__str__`, `__repr__`, `__del__`), and utility methods like `@staticmethod` and `@classmethod`.

The main goal is to build a clean, validated, and reusable class while respecting Python conventions and project constraints.

---

## Learning Objectives
By the end of this project, you should be able to explain and use:

- What OOP is and why it matters
- Classes vs objects
- Private attributes and name mangling (`__attribute`)
- Properties (`@property`) and setters for validation
- Instance attributes vs class attributes
- Special methods:
  - `__init__` (initialization)
  - `__str__` (human-readable string)
  - `__repr__` (recreatable representation)
  - `__del__` (destructor behavior)
- `@staticmethod` vs `@classmethod`
- Using `eval()` with `__repr__` output (recreation)
- Building methods like `area()` and `perimeter()` correctly
