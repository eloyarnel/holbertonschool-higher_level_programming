Python - Import & Modules
Description

This project introduces the basics of Python modules, imports, command line arguments, and coding style using pycodestyle. It focuses on writing clean, executable Python scripts while following Python best practices.

Learning Objectives

By the end of this project, you should be able to explain:

How to import functions from another file
How to use imported functions
How to create a module
How to use the built-in dir() function
How to prevent code from executing when imported
How to use command line arguments in Python


Requirements
Allowed editors: vi, vim, emacs
Ubuntu 22.04 LTS
Python version: 3.10.*
All files must end with a new line

First line of all files:

#!/usr/bin/python3
Code must follow pycodestyle version 2.7.*
All files must be executable
