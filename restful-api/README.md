# RESTful API Project

## Description

This project introduces the basics of RESTful APIs using Python. It covers HTTP and HTTPS, API consumption with `curl`, working with APIs in Python using `requests`, building a simple server with `http.server`, creating routes with Flask, and securing endpoints with Basic Authentication and JWT.

## Learning Objectives

- understand HTTP and HTTPS
- consume API data with `curl`
- fetch and process JSON data with Python
- save API data into CSV files
- build a simple API with `http.server`
- create API routes with Flask
- handle `GET` and `POST` requests
- implement Basic Authentication and JWT
- understand authentication and authorization

## Requirements

- Python 3.9
- Flask
- Flask-HTTPAuth
- Flask-JWT-Extended
- requests
