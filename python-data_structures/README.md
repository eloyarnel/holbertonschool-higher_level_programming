# Python - Switch Values

## Description
This project demonstrates how to swap the values of two variables in Python using a clean and Pythonic approach.
It focuses on understanding tuple unpacking, a core concept that allows swapping values without using a temporary variable.

---

## Learning Objectives
By completing this task, you will understand:

- How variable assignment works in Python
- How to swap two variables in a single line
- What tuple unpacking is and why it is useful
- How Python differs from other languages when handling variable swaps

---

## Requirements
- Language: Python 3
- No imports allowed
- Output must match the expected format
